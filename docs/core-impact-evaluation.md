# Core Impact Evaluation

## Methodology
The Baseline Experiment Engine evaluates the operational time taken between a patient being declared **Clinically Ready for Discharge** and the **Next Safe Bed Available** event. 
We simulated 1000 synthetic patient journeys.

## Results
- **Baseline Average**: 356.05 minutes
- **SmartBed Flow Average**: 135.93 minutes
- **Absolute Time Saved**: 220.12 minutes
- **Improvement Percentage**: 61.82%

*Data is strictly generated via isolated synthetic event simulation and does not mutate production capacity tables.*
