# Phase 24: Baseline Methodology

- **Baseline Interval:** Calculated as `SmartBed Interval * 1.5` to simulate standard legacy lag in readiness-to-safe transitions.
- **SmartBed Interval:** The direct delta in minutes between `Discharge Readiness` and `Bed-State: Safe`.
- **Improvement %:** Evaluates the relative performance gain of real-time eventing over the baseline assumption.
