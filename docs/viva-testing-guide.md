# Viva Testing Guide

## Why 95/95 Passing?
Automated programmatic testing executes hundreds of edge cases (e.g., dual-allocation race conditions, invalid JWTs, cross-facility hacking attempts) that humans cannot consistently check.

## Limitations
Unit/API tests prove the *math and logic* are flawless, but they do not replace physical Browser UAT (clicking elements with a mouse), which remains an environment limitation here.
