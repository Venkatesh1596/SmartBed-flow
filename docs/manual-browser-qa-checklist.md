# Manual Browser QA Checklist
*(Browser automation is unavailable in this environment)*
1. Log in with `SYSTEM_ADMIN` credentials.
2. Navigate through all sidebar links (Dashboard, Command Center, Executive, etc.).
3. Verify that the Bed Status transition works (Occupied -> Discharge Ready -> Cleaning -> Available).
4. Verify that data freshness indicators display correctly.
5. Check developer console for React rendering errors.
